# 🏥 CarePath -- AI-Powered Healthcare Platform

CarePath is a modern, full-stack healthcare SaaS platform designed to
simplify and enhance the interaction between patients and healthcare
providers. It integrates AI-driven features, appointment management,
health records, and smart recommendations into a single scalable system.

## 🧠 Key Features

### 👨‍⚕️ Patient Features

-   Book doctor appointments
-   View medical history & records
-   AI-based doctor recommendations
-   Medicine reminders
-   Secure authentication (Email + Google)

### 🏥 Doctor Features

-   Manage appointments
-   View patient details
-   Update prescriptions
-   Dashboard analytics

### 🛠️ Admin Features

-   Manage users & doctors
-   System monitoring
-   Data control panel

### 🤖 AI Capabilities

-   Smart doctor recommendation engine
-   Health insights & analytics
-   Future-ready AI integrations

## 🧪 Installation & Setup

### 1. Clone the repository

    git clone https://github.com/Nitesh-N-D/CarePath.git
    cd CarePath

### 2. Install dependencies

#### Frontend

    cd frontend
    npm install

#### Backend

    cd backend
    npm install

### 3. Run the application

#### Start backend

    npm run dev

#### Start frontend

    npm run dev

------------------------------------------------------------------------

## 🔐 Environment Variables

Create a `.env` file in the server directory:

    PORT=5000
    MONGO_URI=your_mongodb_uri
    JWT_SECRET=your_secret
    GOOGLE_CLIENT_ID=your_google_client_id
